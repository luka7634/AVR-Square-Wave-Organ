Note Frequency Calculation

Timer values are calculated as:

OCR = F_CPU / (2 × frequency × prescaler)
Example for C4 (261.63 Hz) with F_CPU=16MHz, prescaler=1:
OCR = 16000000 / (2 × 261.63 × 1) = 30578
